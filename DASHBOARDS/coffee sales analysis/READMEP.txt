# ☕ Coffee Orders Data Analysis Dashboard  

This project is a **visualization project** built in **Microsoft Excel**.  
It focuses on analyzing coffee sales data across multiple metrics and presenting insights through an interactive dashboard.  

---

## 🎯 Project Overview
The dashboard enables users to:  
- Track sales trends over time  
- Analyze sales by country  
- Identify the top 5 customers  
- Review total sales per coffee type  
- Explore revenue generated across different product categories  

---

## 🛠️ Process & Techniques
1. **Data Gathering**  
   - Customer information (name, email, country) dynamically retrieved using `INDEX MATCH` from `customer.xlsx`.  
   - Product information (coffee type, roast type, size, unit price) dynamically retrieved using `INDEX MATCH` from `product.xlsx`.  
   - Sales calculated using `Unit Price × Quantity`.  
   - Coffee type and roast type formatted into full names.  
   - Date formatted consistently as `dd/mmm/yy`.  

2. **Analysis & Visualization**  
   - Timeline analysis of total sales.  
   - Sales breakdown by country.  
   - Ranking of top customers.  
   - Sales distribution per coffee type.  
   - Revenue visualization across categories.  

---

## 🛠️ Tools & Skills
- Microsoft Excel  
- INDEX MATCH for dynamic lookups  
- Pivot Tables & Pivot Charts  
- Dashboard design & visualization
