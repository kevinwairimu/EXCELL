# 📊 HR Data Analysis Dashboard  

This project is a **visualization project** built in **Microsoft Excel**.  
It focuses on analyzing key metrics and performance data in the Human Resource department through an interactive dashboard.  

---

## 🎯 Project Overview
The dashboard enables users to:  
- Filter by department  
- Review employee performance ratings  
- Analyze employee distribution by region  
- See the breakdown of male vs. female employees  
- Explore skills, work location, salaries, and leaves taken  

---

## 🛠️ Process & Techniques
1. **Data Cleaning & Formatting** → Ensured consistency, removed duplicates, and handled empty cells.  
2. **Pivot Tables** → Used for key analysis across employee demographics, salaries, and performance.  
3. **Pivot Charts & Dashboard Design** → Built interactive charts to visualize HR metrics clearly.  

---

## 🛠️ Tools & Skills
- Microsoft Excel  
- Pivot Tables & Pivot Charts  
- Power Query (for cleaning and transformation)  
- Dashboard design & visualization   

---

💡 *This project demonstrates how HR data can be transformed into actionable insights using Excel dashboards.*
